# Relay Shield 实施选择

## Sound

### 本轮继续使用 Cloudflare（高置信）

用户希望直接在 Cloudflare 承载 Hub，所以保留现有 Worker 与 Durable Objects。只有实测证明自有域名仍不可达时，才重新启动非 CF 部署；当前不增加第二套生产服务。这是用户明确选择，记在这里供后续接手者继承。

### 诊断只报告可观察到的链路（高置信，01）

代理电脑能访问健康接口时，只标记代理侧成功。浏览器 WebSocket 错误没有可靠的 DNS/TLS 细分，因此扩展报告连接失败及时间，不能替用户推断被哪一层过滤。计划未规定具体 CLI 探测方式，采用 Node 自带 DNS/TLS 与有期限的 HTTPS 探测，不增加依赖。

### Cloudflare 限额按路由生效（中置信，03）

一个浏览器对应一个 Durable Object。它可以限制该浏览器的未认证连接和等待请求数量，但无法统计所有浏览器合起来的每 IP 配额。本轮实现本地额度，不把它描述成全球每 IP 防护；需要后者时在边缘增加独立规则。平台先接收完整 WebSocket 消息，应用的大小限制只约束后续处理，不能避免平台最初的分配。

### 两端时钟需保持同步（中置信，05 集成）

操作端发送带认证的绝对截止时间，扩展仅接收尚未到期且不超过本机未来 30 秒的请求。这样恶意 Hub 无法把旧操作长时间扣住后再执行；代价是电脑时钟相差较大时会拒绝正常请求。计划未指定跨主机时间约束，当前选择依赖系统时间同步。影响所有同步 RPC；若真实环境无法保证同步，应在认证握手内协商相对时间边界，不能直接去掉过期检查。判定 sound：优先拒绝陈旧操作，但可用性需远端实测。

### 异步任务保留自身期限（中置信，05 集成）

提交异步任务时，加密请求 30 秒内必须到达并完成提交；已接受任务仍按原有最长 120 秒任务期限执行。用户主动提交的长任务因此不会在提交请求返回后立刻取消。计划要求保留原有任务语义而未明确两种期限的关系，这里让提交和任务各自负责期限。影响异步调用者：想停止任务仍需发送认证取消或关闭远控。判定 sound：保持既有行为且工作有上限。

### 固定协议额度与主动清理（中置信，04/05）

同一个浏览器最多保留 16 个待握手或活动会话，单会话最多 10 分钟；正常 CLI 命令结束会发送加密关闭并释放额度。若代理突然退出，额度在后续设备操作检查到过期时释放。计划未规定具体常数，当前选有限内存并复用现有生命周期，未增加后台清理计时器。影响需要大量并行客户端的工作；额度以共享 LIMITS 为准。判定 sound：避免无界状态，额度不足时明确报错。

### 密钥格式和撤销范围（高置信，04/05）

用户复制的 `br2` ID 同时包含 Hub 源、路由和随机主密钥；Hub 只收到另一把派生的转发令牌。更换地址或重置 ID 会换主密钥并使旧连接失效，不迁移旧明文凭据。具体编码由实现确定，原计划已要求新秘密和源绑定。影响所有客户端：必须成套升级并重新配对；ID 本身是凭证，不能公开。判定 sound：旧 Hub 已知道的秘密不能充当新加密密钥。

### 丢失结果不自动重放写操作（高置信，05）

例如点击已经发生、返回途中断线时，SDK 保留任务 ID 并尝试认证取消，但不会再点一次。下一次用户明确发起的请求才重新握手。计划要求保留不确定结果，这里选择清掉失败会话、取消等待中的并发调用各自遵守自己的期限。影响调用者：应查询任务或页面结果后决定重试。判定 sound：无法证明未执行时，自动重试可能重复提交。

### 区分传输错误和浏览器错误（高置信，05）

Hub 返回“成功”或“页面失败”都不能直接作为执行结果；SDK 只有验证密文和对应请求 ID 后才接受浏览器结果。外层故障只标记 transport_error 并保留受限格式的传输代码。计划未定外层错误形状，采用明确来源边界以免调用者把恶意 Hub 的回答当作执行事实。影响错误处理代码，需要依据认证结果而非 Hub 状态判断页面行为。判定 sound。

### 不追加新服务与依赖（高置信，03–07）

加密使用浏览器和 Node 共有的 Web Crypto；部署复用现有 Worker、Durable Objects、自定义域，验证复用 Node tests、Playwright 和现有 ws。计划允许实现方式选择，本轮没有增加数据库、队列、密钥服务或生产 npm 依赖。未来维护集中在一个共享协议模块、现有连接所有者和一个 Hub。判定 sound：现有平台已覆盖需要的能力。

### 未完成的远端验收保持打开（高置信，07）

当前电脑能连自有域，也能用模拟浏览器执行器完成线上加密往返，但不能据此推断目标远端运营商同样可达。本轮部署供实际配对使用，保留 01/07 的远端测量门槛，不把规格归档为全部完成；非 CF 和 HTTPS 回退待实际阻断证据再启动。当前没有远端环境可供代测。影响交付标签：代码已部署不等于网络稳定性已验收。判定 sound。

### 使用平台自动关闭回复（高置信，07）

真实 Worker 测试发现停用后连接未结束，原因是旧兼容日期不会自动回复关闭帧。增加 web_socket_auto_reply_to_close 标志后测试进程正常退出，保留原兼容日期以避免其他运行时行为一起变化。计划未指定平台关闭细节，优先使用原生能力而非增加客户端强制终止代码。判定 sound；最后一次线上配置更新因 Cloudflare OAuth 失效而待发布。
